# GST 核心规则（2024-01 起标准税率 9%）

## 注册门槛
- 强制注册：过去 12 个月应税营业额 > S$1M
- 自愿注册：预计未来 12 个月营业额 > S$1M
- 注册后：必须持续 ≥ 2 年

## 税率
| 类型 | 税率 | 适用 |
|------|------|------|
| Standard-rated | 9% | 新加坡境内商品与服务 |
| Zero-rated | 0% | 出口货物、国际服务 |
| Exempt | — | 金融服务、住宅租售 |

## GST F5（季度申报）
- 提交周期：按季度（1-3 / 4-6 / 7-9 / 10-12）
- 截止日：季末后 1 个月（如 Q4 截止日 = 次年 1 月 31 日）
- 提交渠道：IRAS myTax Portal（GIRO 自动扣款）

## F5 关键栏目
| Box | 内容 |
|-----|------|
| Box 1 | 标准税率应税销售总额 |
| Box 2 | 零税率销售 |
| Box 3 | 免税销售 |
| Box 4 | 销售总计（Box 1+2+3）|
| Box 5 | 应税采购总额 |
| Box 6 | 销项税 Output Tax |
| Box 7 | 进项税 Input Tax |
| Box 8 | 应缴 / 应退（Box 6 − 7）|

## 常见违规
- 逾期提交：S$200/月，最高 S$10,000
- 延迟付款：5% 罚金 + 月利 2%
- 错误申报：最高 2 倍少缴税额 + 罚金

## Major Exporter Scheme (MES) / Import GST Deferment Scheme (IGDS)
- 大额出口商可申请 MES，进口 GST 暂免
- IGDS：GST 递延至申报时，无需先垫付
