# 新加坡公司法核心条款摘要

## s.17 注册要求
- 至少 1 名本地居民董事（Singapore Citizen / PR / EntrePass / EP holder）
- 至少 1 名股东（自然人或法人，100% 外资允许）
- 必须有新加坡注册办公地址（不可为 PO Box）
- 必须在注册后 6 个月内任命持牌公司秘书（Filing Agent / Professional Secretary）

## s.145 董事资格
- 年龄 ≥ 18 岁
- 未破产、未被取消资格
- 未被判定 CDSA 等相关罪行

## s.175 年度股东大会（AGM）
- 首次 AGM：须在公司成立后 18 个月内召开
- 后续 AGM：每日历年召开一次，且间隔不超过 15 个月
- 私人公司可通过全体股东决议豁免 AGM（Section 175A）

## s.197 年度申报（Annual Return, AR）
- 提交渠道：ACRA BizFile+
- 截止日：AGM 后 30 天内（或 FYE 后 7 个月内，若豁免 AGM）
- 小公司可豁免审计（s.205C 小公司概念：满足 2/3 — 收入 ≤ S$10M、资产 ≤ S$10M、员工 ≤ 50）

## s.201 财务报表
- 必须遵循 SFRS 或 SFRS for Small Entities
- 须董事签署、经 AGM 通过
- 符合小公司条件可免除审计，但仍需编制完整报表

## 常见违规处罚
| 违规 | 罚款 |
|------|------|
| 逾期 AR | S$300 起，累进至 S$600 |
| 未任命秘书 | S$1,000 |
| 未提交账目 | 高达 S$5,000 + 每日 S$500 |
