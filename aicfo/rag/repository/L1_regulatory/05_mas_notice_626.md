# MAS Notice 626 关键要求

## 客户尽职调查（CDD）
- 建立业务关系前必须完成：
  1. 身份识别与核实（IDV）
  2. 受益所有人识别（UBO，≥ 25% 所有权/控制）
  3. 业务目的与性质了解
  4. 持续监控

## 加强尽职调查（EDD）适用情形
- 高风险客户（PEP、高风险司法管辖区、复杂结构）
- 非面对面建立关系
- 涉及现金大额交易（> S$20,000）

## PEP 处理
- 识别：外国 PEP、国内 PEP、国际组织 PEP
- 要求：高管批准、资金来源说明、持续加强监控

## 可疑交易报告（STR）
- 发现即报：向 STRO（可疑交易报告办公室）提交 STR
- 不得告知客户（Tipping-off 违法）

## 记录保存
- 至少 5 年（关系终止后）
- 包括：身份文件、交易记录、分析记录

## AiCFO KYC Agent 对标实现
- Singpass MyInfo → IDV
- Dow Jones / World-Check → 制裁名单与 PEP 筛查
- UBO 识别：股东结构 ≥ 25% 自动标记
- 置信度 < 0.85 或 hits > 0：自动升级人审（CSP 持牌审核员）
